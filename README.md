## 📌 About the Repository

This repository contains the laboratory programs, source codes, algorithms, sample outputs, and supporting resources for the **Data Structures Laboratory** course.

The laboratory focuses on implementing fundamental data structures and solving computational problems using the **C programming language**.

The repository is designed to help students:

- Understand fundamental data structures.
- Implement data structures using C.
- Develop menu-driven programs.
- Analyze algorithms and data structures.
- Practice problem-solving through open-ended experiments.
- Prepare for CIE and SEE laboratory examinations.
- Maintain a systematic digital laboratory record.

# 🎯 Course Outcomes

After completing this laboratory course, students will be able to:

### CO1
Develop C programs to implement fundamental data structures and their operations for solving computational problems.

### CO2
Make use of appropriate data structures to organize, store, and manipulate data for solving real-world problems using C.

### CO3
Build a laboratory record consisting of:

- Problem Statement
- Algorithm / Design
- Data Structure Representation
- C Implementation
- Program Output
- Observations
- Results
- Appropriate Inferences

# 🔵 PART-A – Fixed Set of Experiments

## Experiment 1 – Library Management using Structures

Develop a C program to manage library book records.

### Concepts Covered

- Structures
- Dynamic Memory Allocation
- Functions
- Searching
- Menu-driven programming

### Requirements

Define a structure `Book` containing:

- Book ID
- Title
- Author
- Price
- Availability Status

Dynamically allocate memory for `N` books.
