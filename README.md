# NutriQuest prototype

A responsive, child-friendly web prototype for the NutriQuest snack-to-adventure concept. It runs as a static page with no build step or dependencies.

## Open it

Open `index.html` in a modern browser. On first visit, choose a generated explorer identity and confirm the prototype grown-up permission checkbox. Progress, redeemed demo codes and demo order details are stored in browser local storage.

## Demo interactions

- Pack codes: `QUEST-DEMO01`, `QUEST-DEMO02`, `QUEST-DEMO03` (each once per browser profile)
- Class code: `CLASS-DEMO1`
- Parent Zone: open “For the grown-ups” and answer `6 + 7`
- Complete a puzzle or daily discovery to earn XP. Wrong answers do not remove XP.
- Add a filename in “Show your working”; the file is not uploaded.
- Parent Zone includes product placeholders, a demo Quest Box order, controls and privacy notes.

## Prototype boundary

This is a front-end demonstration, not a production child account or commerce system. Local storage is not secure authentication or server-side code redemption. QR camera scanning, parental consent/authentication, secure backend validation, verified product label/manufacturing data, payment, delivery, moderation, retention/deletion policy and applicable legal review remain production work. Product facts are marked `[FROM LABEL]`, `[MANUFACTURER / PROCESS]` or `[TO CONFIRM]` where not supplied. Sample class/team/event figures are demo content.

The interface deliberately avoids public child profiles, chat, comments, location sharing, profile photos and individual public rankings. Team and school views present group-level progress.
